# Getting help

| You want to | Go to |
| --- | --- |
| Report a bug in a control, or ask how to use one | That control's repository — every listing on <https://pcfhub.dev> links to it |
| Get your own control onto the hub | An issue on [`pcfhub/_template`](https://github.com/pcfhub/_template/issues); <https://pcfhub.dev/publish> walks through it |
| Report a problem with the template, its rig or its workflows | [`pcfhub/_template` issues](https://github.com/pcfhub/_template/issues) |
| Correct something the Claude Code skills say | [`pcfhub/pcfhub-controls-skill` issues](https://github.com/pcfhub/pcfhub-controls-skill/issues) |
| Report something wrong on pcfhub.dev itself | The contact form at <https://pcfhub.dev/contact> |
| Report a security problem | Privately, as [SECURITY.md](SECURITY.md) describes |

Everything here is maintained in people's own time, so a clear report — what
you did, what you expected, what happened, and on which host and version —
gets an answer soonest.
